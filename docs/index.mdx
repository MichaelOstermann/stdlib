## Fast & Memory efficient

[How we did it](./00-principles/01-performance.mdx).

Our port of [ts-pattern](https://github.com/gvergnaud/ts-pattern) for pattern matching with type-safe exhaustiveness checks:

| | stdlib | ts-pattern |
|---|---|---|
| Time per call | 2 ns | 187 ns |
| Bytes per call | 0 B | 1.7 KB |

`Array.map`

| | stdlib | remeda | immer | mutative |

| Something changed | 921 ns · 8.2 KB | 4.0 µs · 8.2 KB | 434 µs · 155 KB | 250 µs · 75 KB |

`Object.setPath`

| | stdlib | remeda | immer | mutative |

Nothing/Something changed: Our functions return the original input when nothing changed:

```ts
const a = [1, 2, 3]
const b = Array.map(a, i => i)
a === b // true
```

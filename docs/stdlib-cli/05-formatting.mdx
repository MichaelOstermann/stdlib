## Output

What `CLI.run` prints for what an action returns:

- `Ok(null)` or nothing: nothing
- `Ok(string)`: the string as it is
- `Ok(value)`: `CLI.formatJSON(value)`
- `Err(error)`: to stderr, the exit code becomes 1, mistakes in commands and options are underlined with a suggestion when there is one, everything else uses `CLI.formatError(error)`
- Thrown errors: like `Err(error)`
- `--help` or a command without an action: `CLI.commandHelp(command)`
- RPC commands: `{ ok, value }` as JSON, also when it fails

## Formats

```ts
// JSON as readable text, like YAML:
CLI.formatJSON(value)
// On one line when it fits, with limits for long arrays, objects and strings:
CLI.formatJSON(value, { compact: true, maxItems: 100, maxString: 1000, width: 80 })
// Anything that went wrong as readable text, takes the same options:
CLI.formatError(error)
// What CLI.run prints for an execution:
CLI.formatExec(await CLI.exec(root, { name: "miko" }))
```

## Help

```ts
// The help of a command, with options that every command has:
CLI.commandHelp(command, { globalOptions: { help: CLI.boolean() } })
// With an example of how to run it, when every required option has an example:
CLI.commandHelp(command, { path: ["miko", "members", "add"] })
// The options of a command:
CLI.optionsHelp({ foo: CLI.boolean() })
// One option, fit into a width:
CLI.optionHelp("foo", CLI.boolean(), 80)
```

---
title: Prompts
---

This library ships a collection of prompts:

- Manually ask for text input, confirmation, etc.
- Prompt for a command to execute when running one that has no action (list of all subcommands with filter input)
- Prompt for all options when running a command with no flags
- Prompt for missing or invalid options

Unless you manually ship a prompt (`CLI.confirm()`), these prompts are only available in specific environments: `stdin` and `stdout` must be TTYs, disabled for agents, CI and RPC.

```ts
// Disable interactive prompts:
CLI.run(command, { name: "miko", prompt: false })
CLI.exec(command, { name: "miko", prompt: false })
```

```ts
// Render a filter input and list selection to pick a command:
const commands = CLI.pickableCommands(command)
const picked = await CLI.promptCommand(commands)
```

```ts
// Prompt for options:
const options = await CLI.promptOptions({ foo: CLI.boolean() })
const option = await CLI.promptOption("foo", CLI.boolean())
```

```ts
// Ship your own prompts:
const ok = await CLI.confirm({ prefix: () => "Continue? " })
const name = await CLI.prompt({ placeholder: "Your name" })
const color = await CLI.select({ choices: ["red", "green"] })
```

```ts
// Custom rendering if the default prompts are not enough:
const name = CLI.input()

// Draw lines:
const stopRender = CLI.render(({ width }, done) => [
    `Name: ${done ? name.$value() : name(width - 6)}`,
])

// Keybindings:
const stopKeys = CLI.onKey((key) => {
    if (key.name !== "Enter") name.onKey(key)
    if (key.name !== "Enter") return
    stopKeys()
    stopRender()
})
```

:::tip
`CLI.render` uses an [effect](../stdlib/effect) under the hood, so use signals to rerender.
:::

```ts
// A full screen of its own, like less or vim:
const leave = CLI.alternateScreen()

// Clicks and the wheel, with x and y counting from the top left:
const stopMouse = CLI.onMouse((mouse) => {
    if (mouse.name === "WheelUp") $scroll((scroll) => scroll - 1)
    if (mouse.name === "WheelDown") $scroll((scroll) => scroll + 1)
    if (mouse.name === "MouseDown") select(mouse.y)
})
```

While `CLI.onMouse` listens, the terminal selects text only with Shift held down.

`CLI.render`, `CLI.onKey`, `CLI.onMouse` and `CLI.alternateScreen` give the terminal back when the process exits, or gets SIGINT or SIGTERM. After a signal, the process exits like the signal would, unless it listens for the signal itself.
